# Security Policy

## Reporting a Vulnerability

We take the security of Magrathea Writer and the confidentiality of authors' literary work very seriously.

If you believe you have discovered a vulnerability, **do not open a public GitHub issue**. Instead, please submit a report through GitHub **Private Vulnerability Reporting**:

👉 [Report a security vulnerability](https://github.com/rhuanlima/magrathea-writer/security/advisories/new)

If you cannot access GitHub Private Vulnerability Reporting, send an encrypted email directly to the maintainer at **rhuan.lima@gmail.com**.

---

## Disclosure Policy & Timelines

We adhere to a coordinated responsible disclosure policy:
- **Receipt confirmation**: within **7 days**.
- **Initial technical assessment & triage**: within **14 days**.
- **Critical / high-severity fixes**: aimed for **up to 30 days**.
- **Coordinated public disclosure**: after fix deployment or **up to 90 days** from original report, whichever comes first.
- Credit will be given to the reporter in release notes and security advisories (unless you request anonymity).

For our comprehensive threat model, cryptographic architecture, and hard security principles, please read [docs/SECURITY.md](docs/SECURITY.md).
